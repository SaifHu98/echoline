# Accessibility System — ECHO//LINE (أصداء)

## 1. Multi-Modal Timeline Identity
Timelines are never distinguished solely by color:

| Timeline | Color | Shape Symbol | Sound Motif | Secondary |
| :--- | :--- | :--- | :--- | :--- |
| **The Past** | `#D4AF37` (Amber) | `◆` (Diamond) | Warm acoustic chimes | Dark Green |
| **The Present** | `#4A90E2` (Steel Blue) | `▲` (Triangle) | Industrial clockwork | Slate Gray |
| **The Future** | `#9013FE` (Violet) | `●` (Circle) | Cold resonant synth | Cyan |

## 2. Visual & Motor Accessibility Features
* **High-Contrast UI**: Increases background opacity and contrast ratios.
* **Reduced Motion**: Disables rapid spatial ripple scale animations and screen shake.
* **Scalable Font Size**: Adjustable from 80% to 160% without UI button clipping.
* **Auditory Captions**: Environmental sounds (water rush, chisel, gear clicks) generate visual text captions (e.g. `[♪ Water surge]`).
