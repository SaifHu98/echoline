# Game Design Document — ECHO//LINE (أصداء)

## 1. Product Vision
**ECHO//LINE (أصداء)** is a cooperative cross-timeline multiplayer social puzzle game for 2–4 players.
Players occupy different timelines of the same physical district (**The Past**, **The Present**, **The Future**) and work together to prevent a catastrophe by creating cross-timeline causal echoes.

## 2. The Clocktower District Vertical Slice

### Interacting Subsystems:
1. **Water Pressure System**:
   * *Past*: Clear debris from canal -> Open sluice gate.
   * *Present*: Basin floods -> Diverts water to turbine.
   * *Future*: Hydro turbine activates -> Generates 50–100 MW power.
2. **Clocktower Mechanism & Resonator**:
   * *Present*: Replace missing bronze gear -> Mechanism begins ticking.
   * *Future*: Resonator synchronizes with the subterranean gate.
3. **Historical Master Code & Stabilizer**:
   * *Past*: Engrave builder code onto archive tablet (`CHRONOS_77`).
   * *Present*: Chemically restore faded archive manuscript.
   * *Future*: Enter verified code into gate console -> Engage stabilizer anchors.

## 3. Multiple Victory Outlines
* **Perfect Restoration**: Water, mechanism, tree canopy bridge, resonator, and gate stabilizer all fully calibrated.
* **City Saved with Sacrifices**: Gate stabilizer engaged without frequency tuning; district saved with lingering anomalies.
* **Temporal Collapse (Defeat)**: Catastrophe timer expires before stabilizers are anchored.
